AUTHENTICATOR — CORE COMMANDS & PUBLISH REFERENCE
========================================================================

0. DOWNLOAD & INSTALL THE PACKAGE
   composer require ataurbdx/authenticator

------------------------------------------------------------------------
1. SETUP & INSTALLATION (ON-DEMAND & MODULAR — TRANSLATOR STYLE)
------------------------------------------------------------------------

   A. INTERACTIVE INSTALLER:
      php artisan authenticator:install

   B. FULL SUITE INSTALLATION (All modules: Core, Profile, OTP, 2FA, PIN, Social):
      php artisan authenticator:install --all

   C. CORE AUTH ONLY (Sign-in, Sign-up, Account Gateway, Password Reset):
      php artisan authenticator:install --core

   D. USER PORTAL ONLY (Dashboard, Profile Management, 5 Isolated Credential Forms):
      php artisan authenticator:install --profile

   E. MULTI-MODULE INSTALLATION:
      php artisan authenticator:install --type=core,profile,otp

------------------------------------------------------------------------
2. GRANULAR MODULE PUBLISH TAGS (VENDOR:PUBLISH)
------------------------------------------------------------------------

   A. CONFIG & ASSETS:
      php artisan vendor:publish --tag=authenticator-config
      php artisan vendor:publish --tag=authenticator-assets
      php artisan vendor:publish --tag=authenticator-service

   B. MODULE 1: CORE AUTH:
      php artisan vendor:publish --tag=authenticator-core               # Full Core bundle
      php artisan vendor:publish --tag=authenticator-core-controllers   # Controllers -> app/Http/Controllers/Authenticator
      php artisan vendor:publish --tag=authenticator-core-views         # Views -> resources/views/authenticator
      php artisan vendor:publish --tag=authenticator-core-routes        # Routes -> routes/authenticator/core.php
      php artisan vendor:publish --tag=migrations-core                  # Migrations -> database/migrations

   C. MODULE 2: PROFILE & PORTAL:
      php artisan vendor:publish --tag=authenticator-profile            # Full Profile bundle
      php artisan vendor:publish --tag=authenticator-profile-controllers# AuthenticatorController -> app/Http/Controllers/Authenticator
      php artisan vendor:publish --tag=authenticator-profile-views      # Views -> resources/views/authenticator/profile
      php artisan vendor:publish --tag=authenticator-profile-routes     # Routes -> routes/authenticator/profile.php

   D. MODULE 3: OTP VERIFICATION:
      php artisan vendor:publish --tag=authenticator-otp                # Full OTP bundle
      php artisan vendor:publish --tag=authenticator-otp-controllers    # Controller
      php artisan vendor:publish --tag=authenticator-otp-views          # Views -> verify.blade.php & otp/
      php artisan vendor:publish --tag=authenticator-otp-routes         # Routes -> routes/authenticator/otp.php
      php artisan vendor:publish --tag=migrations-otp                   # Migrations

   E. MODULE 4: TWO-FACTOR (2FA):
      php artisan vendor:publish --tag=authenticator-2fa                # Full 2FA bundle
      php artisan vendor:publish --tag=authenticator-2fa-controllers
      php artisan vendor:publish --tag=authenticator-2fa-views
      php artisan vendor:publish --tag=authenticator-2fa-routes
      php artisan vendor:publish --tag=migrations-2fa

   F. MODULE 5: PIN CONTENT LOCK:
      php artisan vendor:publish --tag=authenticator-pin                # Full PIN bundle
      php artisan vendor:publish --tag=authenticator-pin-controllers
      php artisan vendor:publish --tag=authenticator-pin-views
      php artisan vendor:publish --tag=authenticator-pin-routes
      php artisan vendor:publish --tag=migrations-pin

   G. MODULE 6: SOCIALITE:
      php artisan vendor:publish --tag=authenticator-social             # Full Social bundle
      php artisan vendor:publish --tag=authenticator-social-controllers
      php artisan vendor:publish --tag=authenticator-social-views
      php artisan vendor:publish --tag=authenticator-social-routes
      php artisan vendor:publish --tag=migrations-social

   H. MASTER AGGREGATE TAGS:
      php artisan vendor:publish --tag=authenticator-controllers        # All controllers
      php artisan vendor:publish --tag=authenticator-views              # All views
      php artisan vendor:publish --tag=authenticator-routes             # All routes
      php artisan vendor:publish --tag=authenticator-migrations         # All migrations
      php artisan vendor:publish --tag=authenticator-all                # EVERYTHING!

AUTHENTICATOR — CORE COMMANDS REFERENCE
========================================================================

0. DOWNLOAD & INSTALL THE PACKAGE
   composer require ataurbdx/authenticator

------------------------------------------------------------------------
1. SETUP & INSTALLATION (ON-DEMAND & MODULAR — TRANSLATOR STYLE)
------------------------------------------------------------------------

   A. INTERACTIVE INSTALLER (Prompts you to choose modules and UI framework):
      php artisan authenticator:install

   B. FULL SUITE INSTALLATION WITH TAILWIND (Default):
      php artisan authenticator:install --all --framework=tailwind

   C. FULL SUITE INSTALLATION WITH BOOTSTRAP 5:
      php artisan authenticator:install --all --framework=bootstrap

   D. FULL SUITE INSTALLATION WITH BOTH FRAMEWORKS:
      php artisan authenticator:install --all --framework=all

   E. MINIMAL CORE INSTALLATION:
      php artisan authenticator:install --type=core --framework=tailwind
      • Installs: users, user_data
      • Best for: Projects using standard email/phone/username login + Modern UI.

   F. OTP VERIFICATION MODULE ONLY:
      php artisan authenticator:install --type=otp
      • Installs: user_otps
      • Best for: Email/SMS verification, passwordless login, OTP reset.

   G. TWO-FACTOR AUTHENTICATION (2FA) ONLY:
      php artisan authenticator:install --type=2fa
      • Installs: user_2fa
      • Best for: Google Authenticator TOTP & recovery codes on login.

   H. PIN CONTENT LOCK ONLY:
      php artisan authenticator:install --type=pin
      • Installs: user_pins
      • Best for: Privacy screen lock overlay while authenticated.

   I. SOCIAL ACCOUNTS MODULE ONLY:
      php artisan authenticator:install --type=social
      • Installs: social_providers, user_socials
      • Best for: Google, Facebook, GitHub OAuth login + dynamic admin settings.

   J. COMBINED CUSTOM SELECTION (Multi-module):
      php artisan authenticator:install --type=core,otp,pin --framework=bootstrap
      php artisan authenticator:install --type=core,social,2fa --framework=tailwind

------------------------------------------------------------------------
2. ARTISAN PUBLISH TAGS (MANUAL PUBLISHING)
------------------------------------------------------------------------

   A. CONFIG ONLY:
      php artisan vendor:publish --tag=authenticator-config

   B. VIEWS (Published directly to resources/views/auth/ - No vendor folder):
      php artisan vendor:publish --tag=authenticator-views           # Active framework templates
      php artisan vendor:publish --tag=authenticator-views-tailwind  # Tailwind CSS templates
      php artisan vendor:publish --tag=authenticator-views-bootstrap # Bootstrap 5 templates

   C. ASSETS ONLY (JS API Bridge & CSS):
      php artisan vendor:publish --tag=authenticator-assets

   D. MIGRATIONS BY MODULE:
      php artisan vendor:publish --tag=migrations-core
      php artisan vendor:publish --tag=migrations-otp
      php artisan vendor:publish --tag=migrations-2fa
      php artisan vendor:publish --tag=migrations-pin
      php artisan vendor:publish --tag=migrations-social
      php artisan vendor:publish --tag=authenticator-migrations  # All 7 tables

------------------------------------------------------------------------

------------------------------------------------------------------------
